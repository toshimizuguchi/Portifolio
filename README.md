# Portfólio — Estrutura pronta

Este repositório contém um scaffold simples para um portfólio pessoal.

Arquivos principais:

- `html/index.html` — página principal com seções: Sobre, Projetos, Contato.
- `css/style.css` — estilos base, grid de projetos e responsividade.
- `js/main.js` — scripts mínimos (ano dinâmico, smooth scroll e handler demo de formulário).
- `css/img/` — coloque sua foto `perfil.png` aqui.

Como usar:

1. Abra `html/index.html` no navegador (ex.: arrastar o arquivo para o Chrome).
2. Edite textos nas seções `#sobre`, `#projetos` e `#contato`.
3. Para formulário funcional, integre com um serviço (Formspree, Netlify Forms) ou implemente backend.
